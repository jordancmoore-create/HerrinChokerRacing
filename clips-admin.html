How to get the token (one-time, ~15 min)
  1. In the Instagram app, make @herrinchokerracing a professional account (free): Settings → Account type and tools → Switch to professional account — pick Creator or Business.
  2. Go to developers.facebook.com/apps, log in with the Facebook account that manages the team, and Create app. Pick the Instagram use case (“API setup with Instagram business login”). Name it anything, e.g. “Herrin Choker Site”.
  3. In the app dashboard open Instagram → API setup with Instagram business login → Generate access tokens → add the @herrinchokerracing account and log in when prompted.
  4. Copy the long token it shows and paste it above, then hit Connect Instagram.
The token lasts 60 days — the site renews it automatically every week, so this is a one-time setup. If it ever breaks (e.g. the Instagram password changes), just generate a new token and paste it here again. Disconnect the feed.
